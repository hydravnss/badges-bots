# Badges Bots

Extension SillyTavern pour afficher un **badge** (image PNG) à côté du nom des personnages.

## Utilisation

1. Extensions → **Badges Bots**
2. Appuie sur **Ajouter un badge** et choisis une image (PNG de préférence)
3. Coche les personnages sur lesquels l’appliquer

Le badge apparaît à côté du nom dans le chat, la liste des personnages et l’écran d’accueil.

Tu peux ajouter plusieurs badges et les répartir comme tu veux. Un même personnage peut en avoir plusieurs.

## Installation

Depuis SillyTavern → Extensions → Installer une extension :

```
https://github.com/hydravnss/badges-bots
```

Ou clone dans `data/<user>/extensions/badges-bots`, puis recharge la page.
